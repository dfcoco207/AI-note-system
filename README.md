## 项目简介
本系统是面向大一学生的个性化学习辅助工具，实现笔记全生命周期管理，结合大语言模型实现智能问答。用户可以维护个人笔记库，设置AI助手性格，提问时自动匹配相关笔记内容，生成针对性学习解答。

## 核心功能
1. **笔记管理模块**
    - 笔记新增、编辑、删除、查看；标签分类、关键词模糊搜索、时间排序
    - JSON本地文件持久化存储笔记数据

2. **助手配置模块**
    - 自定义AI助手名称、性格风格（严谨专业/幽默鼓励等）
    - 助手配置持久化保存，重启程序配置不丢失

3. **智能笔记相似度检索**
    - 自定义关键词加权相似度算法，标题匹配权重高于内容匹配
    - 根据用户问题匹配库内相关笔记，作为上下文交给大模型

4. **AI智能问答**
    - 调用大模型API，结合匹配到的笔记上下文生成回答
    - 通过提示词工程控制AI输出风格，适配助手性格配置

## 🛠 技术栈
- 后端：Python 3.x，Flask Web框架
- 存储：JSON文件做本地持久化
- AI能力：大模型API调用、提示词工程、自定义相似度匹配算法
- 前端：HTML/CSS（课程提供页面模板）

## 环境配置
复制 .env.example，重命名为 .env，填入你的大模型 API 密钥与接口地址。

## 启动服务
python main.py
